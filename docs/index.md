# Tolkien

**Adaptive, modular document interpretation and rendering engine.**

Tolkien is an extensible engine for identifying, interpreting, processing, and
presenting documents according to their formats, origins, structures, and
characteristics.

The project is in its initial development stage. The first implementations
will be developed against concrete document variants, with each supported
variant validated from identification through terminal presentation.

## Project status

The current repository contains the initial Rust application foundation.
Document recognition, parsing, semantic representation, theming, and rendering
are not implemented yet.
